## 🔬 Mathematical Methodology

1. **Continuous Pressure Index ($\text{PI} \in [0, 1]$):** Evaluates Chase Urgency (45%), Resource Depletion (25%), Phase Leverage (15%), and Bernoulli Closeness with a Crisis Floor (15%).
2. **Context-Adjusted ML Benchmark:** 5-Fold `GroupKFold` by match using `HistGradientBoostingRegressor` to predict expected runs per ball given match dynamics without player ID leakage.
3. **Baseline Normalization:** Evaluates differential uplift against **all non-pressure balls** ($\text{PI} < 0.425$), eliminating small-sample finisher distortions.
4. **Conjugate Empirical Bayes Shrinkage:** 
   $$R_{\text{shrunk}} = \left(\frac{N_i}{N_i + 75}\right) R_{\text{raw}} + \left(\frac{75}{N_i + 75}\right) 0.5000$$
   Guarantees small samples are pulled to the population replacement mean ($0.5000$) while high-volume clutch execution is preserved.
